# 출결 관리 프로그램

첨부된 출결 규정을 기준으로 회원별 출결을 입력하고, 저장할 때마다 실제 Excel 통합 파일과 Excel/Google Sheets 호환 CSV 파일로 자동 동기화하는 로컬 웹 프로그램입니다.

## 실행

```bash
cd /Users/jl/Desktop/CAMI/attendance
python3 server.py
```

브라우저에서 [http://127.0.0.1:8000](http://127.0.0.1:8000)을 엽니다.

## 자동 연동 파일

- `data/attendance.csv`: 행사·회원별 상세 출결 기록
- `data/attendance_summary.csv`: 월별 참여율, 기준 충족 여부, 누적 경고, 벌금 요약
- `data/attendance.xlsx`: `출결기록`, `월별요약` 두 시트가 들어 있는 Excel 통합 파일
- `data/state.json`: 프로그램의 원본 저장 데이터

프로그램에서 출결, 회원, 행사를 저장하면 Excel 통합 파일과 두 CSV 파일이 함께 갱신됩니다. CSV 파일은 Excel 또는 Google Sheets로 바로 열 수 있습니다.

회원 정보에는 이름과 `비고`를 저장하며, 비고에서 `운영진` 또는 `일반 회원`을 선택할 수 있습니다. 운영진을 선택하면 `총괄`, `정보`, `홍보`, `총무`, `출결` 중 부서를 선택할 수 있고, `정보` 부서는 최대 2명까지 등록됩니다. 출결 기록은 `출석 시간`, `이달의 누적 출석`, `전체 누적 출석`으로 표시됩니다.

새 회원 ID는 자동 생성되며 운영진은 `O-`, 일반 회원은 `M-`으로 시작합니다.

## GitHub 공개 페이지

`public/` 폴더는 수정 기능이 없는 공개 확인용 페이지입니다. GitHub Pages는 Python 서버를 실행하지 않으므로, 이 페이지는 `public/data/public-state.json`이라는 공개용 스냅샷만 읽습니다.

로컬 출결 프로그램에서 회원·행사를 저장하면 공개용 스냅샷도 함께 갱신됩니다. Excel 파일을 정리한 뒤 아래 파일을 GitHub에 커밋하고 push하면 공개 페이지가 업데이트됩니다.

```text
public/data/public-state.json
```

GitHub 저장소의 Pages 설정에서 `GitHub Actions`를 배포 방식으로 선택하면 `.github/workflows/pages.yml`이 `public/` 폴더를 자동 배포합니다. 공개 저장소에는 회원명과 출결 현황이 보일 수 있으므로, 외부 공개가 곤란한 개인정보는 공개 데이터에 포함하지 않도록 확인해야 합니다.

## 반영한 규정

- 공식 출사 / 행사 참석: 출석 1회
- 사진 번개 참석: 출석 0.5회
- 오후 2시 이전 참석: 출석 인정, 벌금 없음
- 오후 2시 이후 참석: 출석 인정, 벌금 2,000원
- 사전 연락 후 불참: 출석 0회, 벌금 3,000원
- 사전 연락 없이 불참: 출석 0회, 벌금 5,000원
- 월별 참여율과 전체 참여율 모두 50% 이상이면 기준 충족
- 기준 미달 월 2개월부터 누적 출석 경고를 계산

첫 실행 시 화면을 확인할 수 있도록 샘플 회원·행사·출결 기록이 생성됩니다. 실제 데이터를 입력하기 전에 회원과 행사를 수정해 사용하면 됩니다.
